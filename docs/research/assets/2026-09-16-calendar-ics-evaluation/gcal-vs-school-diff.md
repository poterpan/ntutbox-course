# Google Calendar ics vs 學校 calModeApp.do API — 覆蓋率比對

產生時間：2026-09-14 ｜ 比對區間（inclusive）：**2026-08-01 ~ 2027-07-31**

- Google 來源：`gcal-basic.ics`（661 筆，抓取時 DTSTAMP=20260914T124339Z）
- 學校來源：`cal-raw-threeyear.json` + `cal-raw-app-exact-pm1y.json`，依 `(id, calStart, calEnd, calTitle)` 去重後共 837 筆

## 0. 日期語意怎麼對齊的

兩邊都先化成 **inclusive 的 `[起日, 迄日]`**，時區一律 Asia/Taipei：

學校 API（`calStart`/`calEnd` 是 epoch-ms）：

| 條件 | 迄日 | 區間內筆數 |
|---|---|---|
| `calEnd == calStart` — 2026 年起出現的單日新寫法 | `= 起日` | 58 |
| `calEnd` 正好落在當地午夜 — 傳統 end-exclusive | `= calEnd 當日 − 1 天` | 122 |
| `calEnd` 帶時分（如 21:00 截止） | `= calEnd 當日`（inclusive） | 22 |

Google ICS（RFC 5545）：

- 全天（`DTSTART;VALUE=DATE`）：`迄日 = DTEND − 1 天`。**全域一致 end-exclusive，沒有例外**，
  538 筆全天事件中 `DTEND − DTSTART == 0` 的有 **0 筆**（學校 API 那個壞掉的單日形態在這裡不存在）。
- 有時刻（`...T...Z`，全部是 UTC）：轉 Asia/Taipei 後取日期。
- 缺 `DTEND`（全檔 4 筆，都在 2019–2020，不在比對區間）：`迄日 = 起日`。

## 3. 國定假日（紅字）覆蓋

**先修正一個前提**：學校 API 的 `holiday_system` 筆數**只有週六和週日，一筆平日假日都沒有**。

- 全檔（2024-01-06 ~ 2028-12-31）`holiday_system` 標記日數：**522** 天
- 其中落在平日（週一~週五）的：**0** 天
- 比對區間內：105 天，全部是週末

抽查（`in holiday_system`）：

| 日期 | 星期 | 性質 | 在 holiday_system？ |
|---|---|---|---|
| 2026-10-10 | 六 | 國慶日 | 是 |
| 2026-10-25 | 日 | 光復節 | 是 |
| 2027-01-01 | 五 | 開國紀念日 | **否** |
| 2027-02-04 | 四 | 農曆新年 | **否** |
| 2027-02-08 | 一 | 春節連假 | **否** |
| 2027-06-09 | 三 | 端午節 | **否** |
| 2026-09-28 | 一 | 教師節 | **否** |

所以「國定假日」在**兩邊都不是靠 holiday_system 來的**，而是靠具名事件。
Google ics 在比對區間內帶有 **15** 筆具名國定假日／補假事件，且（見 §2）與學校 API 逐字相同：

- 2027-01-01 ~ 2027-01-01 ｜ 開國紀念日
- 2027-06-09 ~ 2027-06-09 ｜ 端午節
- 2026-09-25 ~ 2026-09-25 ｜ 中秋假
- 2027-02-04 ~ 2027-02-10 ｜ 農曆新年
- 2027-04-06 ~ 2027-04-06 ｜ 兒童節補假
- 2027-04-05 ~ 2027-04-05 ｜ 清明節
- 2027-03-01 ~ 2027-03-01 ｜ 和平紀念日補假
- 2027-04-04 ~ 2027-04-04 ｜ 兒童節
- 2026-10-26 ~ 2026-10-26 ｜ 光復節補假
- 2026-10-09 ~ 2026-10-09 ｜ 國慶日補假
- 2027-02-28 ~ 2027-02-28 ｜ 和平紀念日
- 2026-11-09 ~ 2026-11-09 ｜ 校慶慶祝大會暨園遊會補假
- 2027-05-01 ~ 2027-05-01 ｜ 勞動節
- 2026-10-10 ~ 2026-10-10 ｜ 國慶日

**結論**：換到 Google ics，唯一真正失去的是「週六日的 allDay 標記筆」。
那是純週末，App 端用 `Calendar.component(.weekday)` 即可自行推算，不需要資料源提供。
平日的國定假日／補假紅字兩邊都來自具名事件，完整保留。
